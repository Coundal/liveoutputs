Send Different Scenes to Different Platforms in OBS Studio

Not every platform needs the same picture. A game stream with overlays suits one audience, a clean camera shot suits another, and a mobile platform may want a vertical frame. OBS Studio alone sends one scene to one place, so people usually end up repeating the same image everywhere.

The idea: one input per scene

In LiveOutputs, every input is a scene (or a single source) with its own list of destinations. Build the scenes you want in OBS as usual, then link each one to its platform.

Step by step

  1. In OBS, create one scene per platform, for example “Main stream”, “Clean camera” and “Vertical”.
  2. Open Docks → LiveOutputs and click Add input for each scene.
  3. For every input, add its destinations with the platform address and stream key. SRT destinations also accept a stream ID and a passphrase.
  4. Start each destination when you want it live. They are independent: stopping one does not touch the others.

Follow the live scene

If you prefer one input to follow whatever scene OBS has live, enable that option and define your own scene-to-scene mappings. It switches without cutting the stream.

Keep an eye on the load

  • Total upload is the sum of every output. Leave headroom on your connection.
  • Every active input encodes its own video, so use a GPU encoder when you can.
  • The per-destination bitrate meter helps you notice a struggling connection early.
